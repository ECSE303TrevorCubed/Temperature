# Lab 2 Temperature

Authors: Trevor Swan, Justin Fossum, Trevor Nichols

## Follow these steps to run the C programs

1. Clone the repository locally on your Raspberry Pi
2. cd into the repository directory: `cd Temperature`
3. cd into the source directory: `cd c`
4. Build all 3 parts: `make all`
    - `./temper_poll` runs Part 1, the polling based approach
    - `./temper_interr` runs Part 2, the interrupt based approach
    - `./temper_thresh` runs Part 3, the LED actuation logic
